# Privacy Policy

Last updated: 2026-09-26

This Privacy Policy explains how Folbox handles data when you use the software.

## 1. Scope

This policy applies to the Folbox application and related project documentation in this repository.

## 2. Core Data Principle

Folbox is designed for local operation on your device.

## 3. Data Handling

Based on the current implementation goals:
- Files and metadata are intended to be managed locally on the device.
- User settings are stored locally using system-provided storage mechanisms.
- You are responsible for validating the behavior of the specific version you build or run.

## 4. Permissions

Folbox may request operating-system permissions required by specific features, such as file access.

These permissions are requested only to enable related features. You can manage or revoke permissions in system settings.

## 5. Network Activity

Folbox is intended to work without mandatory cloud sync.

If any feature requires network access, such as update checks or links opened by user action, that activity depends on feature usage and configuration.

## 6. Sharing and Disclosure

The project does not intend to sell personal data.

Any disclosure may occur only when:
- You explicitly trigger an external action.
- Required by law or legal process.
- Needed to protect the project, users, or public safety.

## 7. Data Retention

Locally stored settings remain on your device until changed or removed by you, the application, or the operating system.

## 8. Open Source Transparency

Because this project is open source, data-handling behavior can be reviewed in source code. You should audit and validate builds before production use.

## 9. Changes to This Policy

This policy may be updated over time. The Last updated date indicates the latest revision.
